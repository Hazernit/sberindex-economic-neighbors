# Экономические соседи муниципалитетов

Конкурс СберИндекса, направление «Кластеризация», 2026.
Работа исследует, какие муниципалитеты похожи по структуре потребительских
расходов и как меняются их группы. Данные — **2 016 МО, 24 месяца, 2023–2024**.

## Смотреть результат

- [Краткий методологический отчёт](docs/methodological-report.md)
- [Исполненный исследовательский ноутбук](notebooks/economic-neighbors.ipynb)
- [PDF-презентация для жюри](output/pdf/economic-neighbors-v3.pdf)
- [Редактируемые слайды](output/presentation/economic-neighbors-v3.pptx)
- [Определения метрик и ограничения](docs/metrics.md)

Презентация показывает потребительские профили, динамику и паспорт Майкопа
с шестью сильнейшими реальными связями. Точки расположены в фиксированной
PCA-проекции экономических признаков; это **не географическая карта**.
Полные профили, история и соседи всех МО доступны в результатах и ноутбуке.

Среди сетевых методов выбран Spectral: kNN=30, K=3. KMeans имеет более высокий
силуэт (0,321 против 0,251), поэтому сетевой метод не объявляется лучшим по всем
критериям. 1 003 МО не меняют согласованную группу за 24 месяца; средняя доля
месячных переходов — 9,65%. Эти результаты описательны и не доказывают шоки,
изменение доходов или причинный эффект доступности рынков.

## Получить исходные данные

Официальные файлы получены 09.10.2026. Если сайт требует российские сертификаты,
архивы можно скачать через Яндекс Браузер без изменения системного доверия.

1. Скачать [официальный ZIP](https://www.sberbank.com/common/img/uploaded/files/pdf/sberindex/hackathonlicence.zip).
2. Распаковать три Parquet и PDF лицензии в `data/raw/hackathonlicence/`.
3. На [странице справочника](https://sberindex.ru/ru/research/dataset-borders-and-changes-of-municipalities)
   скачать `t_dict_municipal.rar`; извлечь `t_dict_municipal_districts.xlsx`
   в `data/raw/`. GPKG в этом решении не нужен.

На macOS извлечение XLSX из скачанного RAR:

```sh
bsdtar -xOf t_dict_municipal.rar t_dict_municipal_districts.xlsx > data/raw/t_dict_municipal_districts.xlsx
```

Нужные входы:

```text
data/raw/hackathonlicence/consumption.parquet
data/raw/hackathonlicence/connection.parquet
data/raw/hackathonlicence/market_access.parquet
data/raw/hackathonlicence/Данные_СберИндекс_лицензия.pdf
data/raw/t_dict_municipal_districts.xlsx
```

Схема, единицы и границы проверены по лицензии и справочнику; определения
сохранены в `data/metadata.json`, контрольные суммы — в `outputs/input-inventory.json`.
Средние безналичные расходы жителей не трактуются как суммы расходов всего МО.

## Воспроизвести расчёт

Проверенная среда: Python 3.12, версии зависимостей зафиксированы.
Команды выполняются из корня проекта:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m src.inventory data/raw --output outputs/input-inventory.json
python -m src.prepare
LOKY_MAX_CPU_COUNT=2 python -m src.pipeline
python -m src.build_evidence
python -m unittest discover -s tests -v
```

На тестовом Mac полный расчёт занимает около 20 секунд. Время зависит от машины.
Параметры поиска и seeds — `config.json`. Исходные файлы не перезаписываются.
При смене конфигурации следует заново проверить содержательную интерпретацию:
часть сопровождающего текста описывает зафиксированный конкурсный запуск.

Ноутбук повторяет подготовку и весь расчёт. Его можно выполнить в Jupyter с
ядром созданной среды. Для автоматической проверки и HTML-предпросмотра:

```sh
python -m src.build_notebook
python -m ipykernel install --prefix .venv --name python3 --display-name 'Python 3 (project)'
JUPYTER_PATH="$PWD/.venv/share/jupyter" JUPYTER_RUNTIME_DIR="$PWD/.venv/jupyter-runtime" python -m src.execute_notebook
```

## Устройство решения

| Файл | Назначение |
|---|---|
| `src/prepare.py` | Проверка схемы, ключей, полноты, корзины и справочника |
| `src/network.py` | Взвешенный kNN, KMeans/Spectral/Louvain, согласование меток |
| `src/metrics.py` | SW, CH, S_Dbw, AVI, AVU, MQ и дополнительный DB |
| `src/pipeline.py` | 27 конфигураций, 24 месяца, seeds, сглаживание, внешние сравнения |
| `src/build_evidence.py` | Проверенный набор данных для отчёта и методологический текст |
| `src/build_notebook.py` | Портативный спутник с открытым кодом построения графиков |
| `src/package_submission.py` | Сборка конкурсного архива по явному списку файлов |
| `tests/test_critical.py` | Семь проверок ошибок графа, метрик и согласования меток |

Результаты: `outputs/analysis/` — сравнения методов, профили, назначения групп,
переходы, чувствительность, связи с доступностью рынков и узлы интерактивного
паспорта. Исходные данные, пропуски и критерии исключения проверяемы по ноутбуку.

## Состав конкурсного комплекта

Архив содержит Python-код, JSON-конфигурацию, исполненный ноутбук, результаты,
русский методологический отчёт, PDF и редактируемые слайды. Для чтения PDF
и просмотра результатов Codex или платные API не требуются.

PDF сохраняет проверенное изображение всех девяти страниц. PPTX содержит
нативные таблицы и диаграммы с данными. Некоторые конвертеры PPTX, включая
проверенный экспорт LibreOffice, теряют выделенные связи и маркер Майкопа;
для подачи используйте PDF. Редактирование в PowerPoint отдельно не проверялось.

Исходные архивы скачиваются отдельно по официальным ссылкам выше. Их контрольные
суммы сохранены. Локальные настройки компьютера и оболочка Data plugin
в конкурсный комплект не входят. Локальный интерактивный просмотр в Codex
подготовлен дополнительно и не является зависимостью алгоритмов.

Для повторной сборки комплекта из проверенной рабочей папки:

```sh
python -m src.package_submission
```
