# Определения метрик

Все показатели вычисляются на одной популяции и одном пространстве признаков
в пределах сравнения. Чем выше SW, CH, AVI и MQ, тем лучше по соответствующему
критерию. Чем ниже S_Dbw, AVU и дополнительный DB, тем лучше.

- **SW** — средний силуэт в пространстве квадратных корней долей. При N=2016
  используется фиксированная случайная выборка 2000 объектов, seed=42; CH и
  другие показатели используют все объекты.
- **CH** — отношение межгрупповой и внутригрупповой дисперсии с поправкой
  на число групп и объектов; сравнения N должны быть одинаковыми.
- **S_Dbw** — вариант с векторами дисперсий по формулам (11–17) статьи
  Shahileh et al. (2025), с обычным индикатором плотности внутри шара:
  Scatt + Dens_bw. Scatt — среднее нормы вектора
  дисперсий внутри группы, делённой на норму общего вектора дисперсий.
  Радиус плотности r = sqrt(sum_k ||var(C_k)||)/K. Плотность — количество
  точек внутри замкнутого шара этого радиуса; межгрупповая плотность считается
  вокруг середины центроидов на объединении двух групп. Если оба счётчика
  плотности центроидов нулевые, результат не определён и сохраняется null/NaN.
- **AVI** — среднее `B_kk / v_k`, где B — сумма весов симметричной матрицы
  смежности между группами, v_k = sum_l B_kl. Внутренние рёбра учитываются
  дважды, как в матрице смежности первоисточника.
- **AVU** — `sum_{k≠l} B_kl / (cut_k + cut_l − B_kl) / K`,
  cut_k = v_k − B_kk. Это формула (21), делитель K, **не K(K−1)**.
  Пара без внешних рёбер имеет unifiability=0. Для трёх групп при ненулевом
  межгрупповом весе AVU тождественно 2/3: знаменатель каждой пары — сумма
  весов трёх пар групп. Поэтому в итоговом решении AVU не ранжирует месяцы.
  Это ограничение метрики, а не дополнительное свидетельство качества.
- **MQ** — стандартная взвешенная модулярность Newman–Girvan при gamma=1:
  `sum_k [B_kk / sum(v) − (v_k / sum(v))²]`. Gamma оценки фиксирована,
  даже когда Louvain обучается с иной resolution.

Реализация — `src/metrics.py`. Модулярность сверяется с NetworkX;
AVI/AVU — с графами, на которых ответ считается вручную. Проверены
неориентированность, отсутствие self-loops, совпадающие профили,
перестановка меток, появление новых групп и масштабная инвариантность S_Dbw.

## Первоисточники и варианты

1. Shahileh, Tsyplakova, Antonov (2025), *Cluster Validity across Attribute and
   Network Spaces*, формулы 18–21 для AVI/AVU:
   https://doi.org/10.1134/S1064562425700589
2. Halkidi & Vazirgiannis (2001), *Clustering Validity Assessment: Finding the
   Optimal Partitioning of a Data Set*, DOI 10.1109/ICDM.2001.989517.
   Для сравнения проверена реализация https://github.com/alashkov83/S_Dbw:
   она использует векторы стандартных отклонений, а не дисперсий.
   Её значения не объявляются совпадающими с выбранным вариантом статьи 2025.
3. В формуле (14) статьи 2025 индикатор плотности напечатан как 0 внутри
   шара и 1 снаружи. Здесь явно использован обычный счётчик **внутри** шара
   из определения плотности S_Dbw, а не буквальная инверсия этого индикатора.
   Поэтому выбранный вариант описан формулой, а не только названием индекса.
4. SW/CH/DB: https://scikit-learn.org/stable/modules/clustering.html#clustering-performance-evaluation
5. Модулярность: https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.community.quality.modularity.html

Сеть строится из тех же признаков, на которых считается силуэт. Высокие
сетевые показатели частично следуют из этого построения; они не являются
независимой внешней валидацией и не доказывают экономическую причинность.
